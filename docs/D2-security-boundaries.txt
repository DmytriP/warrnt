1. ШТО ЎЖО ДАКАЗАНА (не заяўлена — вымерана)
=====================================================================
Тры слупы кантролю і іх жывы доказ:

1. ЖУРНАЛ ДЗЕЯННЯЎ (receipt / measurement layer)
   Хто: warrnt/registry.py · GET /receipts · GET /verify
   - Кожнае рашэнне пішацца ў append-only рэестр ДА выканання, fsync на кожным радку.
   - Хэш-ланцуг: hash = sha256(prev + canon(запіс)); /verify пералічвае ад genesis.
   - Доказ: J1–J8 — allow/deny/human усе ў журнале; deny нясе прыналежнасць (хто, што, чаму);
     ухваленне пішацца двойчы (рашэнне + факт выканання, злучаныя exec_hash).
   - Нязменнасць на дыску: паправіць ці выдаліць радок → ланцуг падае на тым самым індэксе
     (J6/J7 broken_at=2). Непашкоджаная копія праходзіць (J8) — гэта не «заўсёды чырвоны» тэст.

   ЗАКРЫТА Ў ГЭТЫМ АКНЕ (было адзінай сур'ёзнай дзіркай, зараз даказана як закрытая):
   - Голы хэш-ланцуг лавіць праўку і выдаленне, але НЕ суцэльны перазапіс. Гэта даказана
     на жывым файле: docs/redteam-rewrite-gap.out («ATTACK (bare chain): verify=True»).
   - Фікс — HEAD ANCHOR (warrnt/anchor.py): пасля КОЖНАГА дапісання вузел падпісвае галаву
     ланцуга ключом выдаўцы (HMAC-SHA256) і піша {head,length,ts,sig} у асобны журнал.
     Перазапіс змяняе галаву → яна не супадае з падпісаным якарам; падрабіць якар нельга без ключа.
   - Доказ: A1–A5 — якар ставіцца на кожным рашэнні; суцэльны перазапіс злоўлены
     («rewrite detected»); папраўлены якар не праходзіць праверку подпісу;
     той самы сцэнар «да/пасля» — docs/redteam-rewrite-gap.out («DEFENCE (anchor): ok=False»).
   - Чалавечая мова для пітча: «журнал невыдаляльны, бо кожную ягоную галаву мы подпісваем ключом,
     якога ў атакавалага няма».

2. ДАЗВОЛЫ (warrant scope + policy на параметрах)
   Хто: warrnt/warrants.py (подпіс), warrnt/policy.py (правілы), seed.py
   - Ордэр нясе scope + TTL + HMAC-SHA256. Брамнік верыць ПОДПІСУ, а не аб'екту ў памяці:
     пашырыць падпісаны ліміт у памяці → адмова да чытання правілаў (verify_live: tamper W-4417).
   - Правілы чытаюць ПАРАМЕТРЫ выкліку ДА выканання: allow / deny / require-human.
   - Доказ: P1–P7 — токен аднаго агента не аўтарызуе іншага; tool па-за scope — адмова;
     адсутны ахоўваемы параметр = fail-closed; ліміт дакладны на мяжы (50000 allow / 50001 deny);
     невядомы агент / пусты токен — адмова; адмоўлены выклік не кранае upstream (лічыльнік не расце).

3. КІЛ-СВІТЧ (revoke / containment)
   Хто: POST /revoke · MCPProxy.revoke
   - Доказ: K1–K8 — revoke па ID ордэра спыняе РОЎНА аднаго агента; астатні флот працуе;
     паўторны revoke = чысты 409 (не краш); невядомы агент = 409 без бакавых эфектаў;
     ордэр у рэестры = revoked; жывы цыкл агента бачыць спыненне на наступным выкліку.
   - Лакальна замераная латэнтнасць спынення: 0,032 с (на жывым цыкле, не дэкларацыя).

Кожную мяжу назвалі ЗАГАДЗЯ, каб не атрымаць пытанне журы пад час пітча.

М1. ~~Журнал tamper-EVIDENT, не tamper-PROOF.~~ ЗАКРЫТА якарам (гл. 1.1).
    Застаецца слова: якар па змаўчанні ляжыць побач (anchors.jsonl) і абараняе ключом, не
    размяшчэннем. У prod паказаць WARRNT_ANCHOR на WORM-сховішча ці іншы хост — гэта адно
    значэнне env, дарабіць 5 хвілін.
М2. Кіл-світч дзейнічае на НАСТУПНЫМ выкліку агента, не вырывае працэс.
    Гэта свядомы выбар (агент — знешні працэс, улады над ім няма). Для імпульсных дзеянняў
    (адзін выклік = адзін пераклад грошай) дастаткова, бо наступны ордэр ужо адкліканы.
М3. WARRNT_DEV=1 выдае токены на GET /agents. Дэма-патрэба, не API.
    Крок: у prod (DEV=0) токенаў няма; для дэма аддаць загадзя зашыты токен, не спіс. (~15 хв)
М4. POST /reset цісне рэестр — для рэгулятара гэта «як выдаліць доказ».
    Цяпер /reset ставіць новы якар (length=0), але сам факт ачысткі ў журнал не трапляе.
    Крок: пісаць запіс «reset» ПЕРАД ачысткай, або дазволіць reset толькі ў dev. (~15 хв)
М5. Асоба агенту — статычны токен на агента (не ephemeral, не ротацыя). Для 24 гадзін хопіць;
    у пітчы называць як наступны крок, не як гатовае.

Парадак працы ў акне, калі застанецца час: М3 → М4 → WARRNT_ANCHOR на вонкавае сховішча.
Усе тры — касметыка супраць таго, што ўжо стаіць; абавязковае толькі калі простайвае.
